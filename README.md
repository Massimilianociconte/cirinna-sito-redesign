# Azienda Agricola Cirinnà – proposta di redesign del sito (demo)

Demo della proposta di redesign del sito web di Azienda Agricola Cirinnà, preparata per la presentazione all’azienda e pubblicata con GitHub Pages.
Non è il sito ufficiale: le pagine non sono indicizzate dai motori di ricerca e i cataloghi PDF non sono inclusi.

Marchi, testi e immagini dei prodotti appartengono a Azienda Agricola Cirinnà.
Design e codice: tutti i diritti riservati. Vietata la riproduzione, anche parziale, e l’uso del design senza accordo scritto.
